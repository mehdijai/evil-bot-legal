
# Evil Bot

Evil Bot is a Discord server bot that automatically sends messages for specific events at predefined times, mentioning a configured role in a designated channel.

The bot is free to use and stores only the Discord server ID, channel ID, and role ID required for its functionality.

## Data Management

Server administrators can use the `/stop` command at any time to stop the bot and permanently delete their server's stored configuration.
